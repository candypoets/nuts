Follow / Join / Belong slide image asset pack

Use these assets to rebuild the slide with editable text and vector shapes.

Recommended build:
- Use 00_full_mockup_reference.png as visual reference only.
- Use 01_social_graph_assembled.png or 01_social_graph_assembled_transparent.png on the left.
- Rebuild the three cards as rounded rectangles; then place:
  - 07_follow_illustration_scene.png or transparent version in card 01.
  - 08_join_illustration_scene.png or transparent version in card 02.
  - 09_belong_illustration_scene.png in card 03; it includes the dark card background around the people, so place it on the right side of the black card.
- Use the icon_*.png files for the Follow / Join / Belong pills and smaller support icons.
- Use 03_timeline_steps.png only if you want the exact timeline look as a flat image; otherwise rebuild it with simple circles/line shapes.
- Full card PNGs are included for quick placement, but editable text will look cleaner if you rebuild the text separately.
