# Agent brief: Community feed static assets

Use the packaged assets to build a cleaner version of the “Communities are the algorithm” slide.

Core idea: the feed is assembled from trusted community inputs, not optimized around engagement metrics.

Preferred composition:
- Left side: headline, two-line body copy, six community pills, closing line.
- Middle: subtle dotted signal lines.
- Right side: product-like “Your feed” panel with stacked update cards.

Recommended primary asset:
- `layouts/community-feed-hero-composition.svg` for editable layout.
- `layouts/community-feed-hero-composition.png` for drop-in raster use.

Use `tokens/design-tokens.css` and `copy/content.json` as the source of truth for styling and copy.
