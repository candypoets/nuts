# Community Feed Static Assets

This package contains static assets for the cleaner “Communities are the algorithm” mockup.

## Start here

- `layouts/community-feed-hero-composition.svg` — editable full hero composition
- `layouts/community-feed-hero-composition.png` — rendered PNG version
- `mockups/community-feed-slide-mockup.png` — original generated mockup
- `preview/index.html` — simple local HTML preview
- `manifest.json` — asset inventory

## Reusable components

- `icons/svg/` and `icons/png/` — community and UI icons
- `components/svg/` — community pills, feed cards, feed panel, signal lines
- `components/png/` — PNG versions of reusable components
- `backgrounds/` — warm beige background as SVG and PNG
- `tokens/` — CSS and JSON design tokens
- `copy/content.json` — structured text content

No font files are included. The assets use a system sans-serif font stack.
